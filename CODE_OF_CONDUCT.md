# Code of Conduct for AnotherLaughingMan-Viewer

Welcome to **AnotherLaughingMan-Viewer**. This is a development fork of the Second Life Viewer.  
We take our work seriously… but not *too* seriously. Please read carefully, laugh responsibly, and follow the rules.

---

## 1. Respect the Code (and the Coders)
- Do not insult contributors, even if their commit messages look like ransom notes.
- Code reviews are for constructive feedback, not stand-up comedy routines (unless the joke is *really* good).
- Remember: tabs vs. spaces is a holy war. Fight it elsewhere.

---

## 2. Keep It Clean
- No malicious code, no sneaky backdoors, no “just testing” infinite loops.
- If your patch breaks the build, you owe everyone else a cookie.
- Documentation is not optional. If you don’t write it, someone else will — badly.

---

## 3. Humor Is Welcome, Chaos Is Not
- Funny comments in code are fine.  
  Example: `// TODO: fix this before it fixes us`
- Prank commits (like renaming every file to “banana.cpp”) are not fine.
- Sarcasm is allowed, but passive-aggressive sarcasm will be treated as a bug.

---

## 4. Collaboration Rules
- Pull requests must be clear, tested, and not written at 3 AM after six energy drinks.
- If you fork this fork, congratulations — you now owe us a README pun.
- Merge conflicts should be resolved with Git, not with duels at dawn.

---

## 5. Enforcement
- Violations will result in stern looks, sarcastic comments, and possibly your code being reverted with extreme prejudice.
- Repeat offenders may be sentenced to writing documentation for obscure build flags.
- The maintainers’ word is final, unless they’re wrong — in which case, prove it with code.

---

## 6. Golden Rule
- **Don’t be a jerk.**  
- **Do be funny.**  
- **Always be helpful.**

---

By contributing, you agree to follow this Code of Conduct.  
Failure to comply may result in your commits being replaced with dad jokes.
